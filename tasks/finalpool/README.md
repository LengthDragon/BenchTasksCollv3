# Final Pool

This directory holds every task that is marked as **implemented** on the Notion
`Task Tracker` board, collected from the developers' branches of
`BenchTasksCollv3`.

Each task is stored under its own folder: `tasks/finalpool/<task-name>/`, with the
same layout as `tasks/examples/example-task`.

Implemented tasks:

- client-portal (lueyang-dev)
- error-tracker (xiaochen_dev)
- expense-tracker (ruige)
- health-monitor (xiaochen_dev)
- media-organizer (haoze)
- price-tracker (fan-dev)
- robots-handler (gyy)
- shipment-tracker (junteng_dev)
- social-connector (junxian_dev)
- tag-manager (gyy)
- task-scheduler (yuxuan-dev)
